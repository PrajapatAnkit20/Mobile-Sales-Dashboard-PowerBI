# 📱 Mobile Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing mobile phone sales data using Microsoft Power BI. The dashboard provides an interactive view of sales performance, customer ratings, payment methods, mobile brands, and geographical sales distribution across different cities in India.

The objective is to transform raw sales data into meaningful business insights through interactive visualizations and KPIs.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Data Cleaning and Data Transformation
- Data Visualization
- Business Intelligence

## 📊 Dataset Overview

The project uses a mobile sales dataset containing **3,835 transaction records** and 14 columns.

| Dataset Information | Details |
|---|---|
| Total Records | 3,835 |
| Total Brands | 5 |
| Mobile Models | 15 |
| Cities | 19 |
| Payment Methods | 4 |
| Data Period | 2021–2024 |

### Key Dataset Columns

- Transaction ID
- Date (Day, Month, Year)
- Day Name
- Brand
- Mobile Model
- Units Sold
- Price Per Unit
- Customer Name
- Customer Age
- City
- Payment Method
- Customer Ratings

## 📊 Dashboard Features

1. **Sales Analysis by City:** Visualizes geographical sales distribution across 19 Indian cities.
2. **Monthly Sales Analysis:** Tracks the quantity of mobile units sold across all 12 months.
3. **Sales by Mobile Model:** Compares sales performance across different mobile models.
4. **Payment Method Analysis:** Analyzes transactions through UPI, Debit Card, Credit Card, and Cash.
5. **Customer Ratings Analysis:** Examines customer ratings from 1 to 5.
6. **Sales by Day Name:** Compares sales performance across different days of the week.
7. **Brand Performance:** Compares total sales, quantity sold, and transactions across five mobile brands.

## 🎛️ Interactive Filters

The dashboard includes interactive slicers for:

- Mobile Model

These filters allow users to explore the data from different perspectives.
